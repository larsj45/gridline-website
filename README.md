# Gridline Education Website

Landing page for Gridline Education - Infrastructure engineering for higher education.

## Deployment

This site is deployed on Vercel. Any push to `main` will trigger a deployment.

## Setup

1. Clone this repository
2. Sign up for [Formspree](https://formspree.io) and create a form
3. Replace `YOUR_FORM_ID` in `index.html` with your Formspree form ID
4. Push to GitHub and connect to Vercel

## Structure

```
├── index.html          # Main landing page
├── images/
│   ├── logo-white.svg  # White logo for dark background
│   └── favicon.png     # Browser favicon
├── vercel.json         # Vercel configuration

```
